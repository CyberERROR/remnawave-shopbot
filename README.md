## 📋 О проекте

**Remnawave ShopBot** — комплексное решение для автоматизированной продажи VPN-конфигураций через Telegram: мощный бот + интуитивная веб-панель на базе **Tabler** для полного управления услугой.

<img src="https://capsule-render.vercel.app/api?type=soft&height=60&color=0:000000,55:030b1f,100:0891b2&text=01%20%C2%B7%20%D0%A3%D0%A1%D0%A2%D0%90%D0%9D%D0%9E%D0%92%D0%9A%D0%90&fontSize=22&fontColor=22D3EE&fontAlignY=55&animation=fadeIn" width="100%" alt="01 · УСТАНОВКА"/>

> [!NOTE]
> **Что нужно заранее:** 🐧 Ubuntu 20.04+ / Debian 11+ · 🔑 SSH с правами `root` · 🌐 домен с A-записью на IP сервера · 📦 Remnawave Platform на целевых хостах · 💾 от 1 GB RAM и 10 GB диска

<img src="https://img.shields.io/badge/ШАГ_1-Подключитесь_к_серверу-0891b2?style=for-the-badge&labelColor=0d1117" alt="Шаг 1"/>

```bash
ssh root@your-server-ip
```

<img src="https://img.shields.io/badge/ШАГ_2-Запустите_установщик-2563eb?style=for-the-badge&labelColor=0d1117" alt="Шаг 2"/>

```bash
curl -sSL https://raw.githubusercontent.com/CyberERROR/remnawave-shopbot/main/install.sh | bash
```

<img src="https://img.shields.io/badge/ШАГ_3-Ответьте_на_вопросы-7c3aed?style=for-the-badge&labelColor=0d1117" alt="Шаг 3"/>

| Вопрос | Пример | 💡 |
|:--|:--|:--|
| 🌐 Домен | `shop.example.com` | должен смотреть на этот сервер |
| 📧 Email | `you@example.com` | для SSL от Let's Encrypt |
| 🔌 Порт вебхуков | `8443` | 443 или 8443 — **рекомендуется 8443** |

Дальше всё автоматически: **Docker + Compose → Nginx (reverse proxy) → SSL через Certbot → контейнеры бота и панели → автообновление сертификата.**

<img src="https://img.shields.io/badge/ШАГ_4-Войдите_в_панель-c026d3?style=for-the-badge&labelColor=0d1117" alt="Шаг 4"/>

```text
🎉 Установка завершена!
Веб-панель:  https://shop.example.com/login
Логин:       admin
Пароль:      admin
```

> [!CAUTION]
> Сразу смените пароль: **Настройки → Настройки панели**. Логин и пароль `admin` / `admin` знают все.

<!-- ═══════════════════════════  UPDATE  ═══════════════════════════ -->
<a id="update"></a>

<img src="https://capsule-render.vercel.app/api?type=soft&height=60&color=0:000000,55:030b1f,100:2563eb&text=02%20%C2%B7%20%D0%9E%D0%91%D0%9D%D0%9E%D0%92%D0%9B%D0%95%D0%9D%D0%98%D0%95&fontSize=22&fontColor=60A5FA&fontAlignY=55&animation=fadeIn" width="100%" alt="02 · ОБНОВЛЕНИЕ"/>

> [!TIP]
> Обновление = **повторный запуск установщика**. Он скачивает свежую версию и пересобирает контейнеры.

<img src="https://img.shields.io/badge/1-Подключитесь_по_SSH-0891b2?style=flat-square"/>&nbsp;
<img src="https://img.shields.io/badge/2-(по_желанию)_сделайте_копию-2563eb?style=flat-square"/>&nbsp;
<img src="https://img.shields.io/badge/3-Запустите_установщик-7c3aed?style=flat-square"/>&nbsp;
<img src="https://img.shields.io/badge/4-Проверьте_логи-c026d3?style=flat-square"/>

```bash
# 1. Подключиться к серверу
ssh root@your-server-ip

# 2. (по желанию) резервная копия папки проекта
cp -r /root/remnawave-shopbot /root/remnawave-shopbot.bak

# 3. Обновить до последней версии
curl -sSL https://raw.githubusercontent.com/CyberERROR/remnawave-shopbot/main/install.sh | bash

# 4. Убедиться, что всё поднялось
cd /root/remnawave-shopbot && docker-compose logs -f
```

<details>
<summary><b>♻️ Если что-то пошло не так — пересоздать контейнеры вручную</b></summary>

```bash
cd /root/remnawave-shopbot && docker-compose down && docker-compose up -d --build
```
</details>

<details>
<summary><b>🛠️ Шпаргалка по командам</b> <sub>(выполнять в <code>/root/remnawave-shopbot</code>)</sub></summary>
<br>

| Действие | Команда |
|:--|:--|
| 📜 Логи в реальном времени | `docker-compose logs -f` |
| 🔁 Перезапуск | `docker-compose restart` |
| ⏸️ Остановка (контейнеры остаются) | `docker-compose stop` |
| ⏹️ Остановка с удалением контейнеров | `docker-compose down` |
| ▶️ Запуск в фоне | `docker-compose up -d` |
| 🏗️ Пересборка и запуск | `docker-compose up -d --build` |
| 🧹 Очистка логов Docker | `truncate -s 0 /var/lib/docker/containers/*/*-json.log` |

</details>

## 🧩 Модули

<details>
<summary><b>🔗 Принудительная подписка</b> — <i>Настройки → Общие</i></summary>
<br>

| Параметр | Назначение |
|:--|:--|
| `force_subscription` | Включить обязательную подписку (`true` / `false`) |
| `channel_url` | Ссылка на канал/группу |
| `terms_url` | Условия использования |
| `privacy_url` | Политика конфиденциальности |

> [!IMPORTANT]
> Бот должен быть **администратором канала**, иначе не сможет проверить подписку.
</details>

<details>
<summary><b>🧪 Спидтесты и мониторинг</b> — <i>2 метода</i></summary>
<br>

| | 📊 SSH-Speedtest | 🌐 Net-Probe |
|:--|:--|:--|
| Что делает | `speedtest-cli` на удалённом сервере | Доступность и пинг по HTTP |
| Нужен SSH | ✅ да | ❌ нет |
| Скорость | полный замер | быстрее |
| Установка | автоустановка из админ-меню бота или панели | не нужна |

**Запуск:** 🤖 бот — `Админ-меню → Speedtest → Выбрать хост` · 🖥️ панель — `Дашборд → «Run speedtests»`

Результаты сохраняются в БД и видны на дашборде у каждого хоста.
</details>

<details>
<summary><b>🤝 Реферальная система</b> — <i>Настройки → Общие</i></summary>
<br>

| 💸 Типы начисления | ⚙️ Дополнительно |
|:--|:--|
| 📊 **Процент с покупки** реферала (например, 10%) | 🏷️ **Скидка реферала** — % для приглашённого |
| 💰 **Фиксированная сумма** за каждую покупку | 🏦 **Минимум вывода** средств |
| 🎁 **Бонус приглашающему** при регистрации | |

Рефссылка генерируется автоматически: `https://t.me/<bot_username>?start=ref_<telegram_id>`
</details>

<details>
<summary><b>🆘 Техническая поддержка</b> — <i>2 режима</i></summary>
